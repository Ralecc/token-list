Put your avatar here as a `.vrm` file, or drag & drop one onto the video in the app.

- `npm run sample-avatar` downloads a free starter model (pixiv's VRM 1.0 sample).
- Make your own for free with [VRoid Studio](https://vroid.com/en/studio).
- Or download one from [VRoid Hub](https://hub.vroid.com/en) and check each model's
  usage conditions: many forbid sexual or violent use.

A file named `<persona-id>.vrm` (e.g. `mia.vrm`) is used for that persona; otherwise the
persona's `"avatar"` file, and failing that the first `.vrm` in this folder.
